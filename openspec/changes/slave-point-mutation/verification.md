# 手工验证清单

- 为 Coil/Discrete Input 配置变位时只显示翻转和独立周期；启动总开关后按周期交替 ON/OFF。
- 为 UInt16、Int16、UInt32、Int32、Float32 分别配置 flip/increment/decrement/random，确认范围、步长、字节序和双寄存器编码正确。
- 给两个点分别设置 200ms 与 1000ms 周期，确认前者变化次数明显更多；关闭总开关后全部停止，重新开启后恢复。
- 保存 `.modbusproj`，关闭并重新打开，确认从站名称、Unit ID、寄存器定义以及变位模式/周期/范围/步长/启用状态保持不变。
- 确认表格行内模式图标约每 2 秒同步，当前值刷新时保持虚拟滚动位置稳定。
- 尝试创建重复地址、跨 2 寄存器重叠及 `Float32@65535`，确认前后端均拒绝且原点位不会因编辑失败丢失。
- 新建连接时指定初始 Unit ID/名称，新增并编辑从站后确认树中始终显示“名称 + ID”。
- 拖动四列表头分隔线，确认表头与虚拟行对齐、最小宽度生效、重启后列宽恢复；名称/备注截断时悬停可见全文。
- 分别从工具栏和右键菜单删除连接、从站、寄存器，确认取消不会删除、确认后才执行。
