# point-mutation 规范

## 新增需求

### 需求:点位级变位配置
每个寄存器点位必须能独立持有一份变位配置 `MutationConfig`,包含 `enabled`(bool)、`mode`(`flip`|`increment`|`decrement`|`random`)、`period_ms`(u64)、`step`(f64)、`min`(f64)、`max`(f64)。该配置必须作为点位定义的一部分随项目文件持久化。加载缺少该字段的旧项目文件时,点位必须默认为"未配置变位"且加载不报错。

#### 场景:配置随项目保存与加载
- **当** 用户为某点位设置变位配置并保存项目,随后重新加载该项目
- **那么** 该点位的变位配置(模式/周期/范围/步长/启用状态)必须与保存前一致

#### 场景:加载无变位字段的旧项目文件
- **当** 加载一个不含 `mutation` 字段的旧项目文件
- **那么** 所有点位必须默认为未配置变位,且加载过程不得报错

### 需求:bool 点位仅支持翻转
对 Coil 与 DiscreteInput(`data_type=Bool`)点位,变位必须仅执行布尔取反,且必须忽略 `mode`/`step`/`min`/`max`。

#### 场景:bool 点位变位翻转
- **当** 一个已启用变位的 Coil 点位当前值为 `false` 并触发一次变位
- **那么** 其值必须变为 `true`,再次触发必须变回 `false`

### 需求:数值点位按 data_type 在工程值层变位
对数值点位,变位必须先按点位的 `data_type` 与 `endian` 解码出工程值,在工程值层应用变位,再按 `endian` 编码写回该点位占用的 1~2 个寄存器。`min`/`max`/`step` 必须以工程值为单位。禁止在忽略 `data_type` 的情况下逐寄存器独立扰动。

#### 场景:Float32 点位变位后仍是有效编码
- **当** 一个 `Float32`(占 2 个保持寄存器)点位触发变位
- **那么** 写回的两个寄存器按相同 `endian` 解码出的浮点值必须等于变位后的工程值,不得破坏编码

#### 场景:变位结果钳制在 data_type 值域
- **当** 变位计算出的工程值超出该 `data_type` 的可表示范围
- **那么** 写回前必须将其钳制到该 `data_type` 的值域内

### 需求:四种变位模式语义
数值点位的变位必须按所配 `mode` 执行:
- `flip`:在两态间切换 —— 当前值 `≤ (min+max)/2` 时取 `max`,否则取 `min`。
- `increment`:每次 `value += step`,越过 `max` 后方向反转(三角波,在 `[min,max]` 间往复)。
- `decrement`:每次 `value -= step`,越过 `min` 后方向反转。
- `random`:在 `[min,max]` 内均匀随机取值。

三角波的当前方向属于运行时状态,禁止持久化。

#### 场景:递增三角波到达上界后反向
- **当** 一个 `increment` 点位的工程值已接近 `max` 并连续触发变位越过 `max`
- **那么** 其后续变位必须转为递减,值在 `[min,max]` 区间内往复且不越界

#### 场景:随机模式落在范围内
- **当** 一个 `random` 点位连续触发多次变位
- **那么** 每次结果必须落在 `[min,max]` 区间内

### 需求:后端统一 tick 驱动且每点独立周期
全部点位变位必须由单个后端长驻 tick 任务驱动,以固定基准间隔扫描;每个启用变位的点位必须按各自 `period_ms` 独立触发(到期才变位),不同点位的周期互不影响。

#### 场景:不同周期的两点各自按期变位
- **当** 点 A 配 `period_ms=200`、点 B 配 `period_ms=1000`,运行 1 秒
- **那么** 点 A 的变位次数必须明显多于点 B,二者各自按其周期触发

#### 场景:未启用点不被变位
- **当** tick 任务运行,但某点位 `enabled=false`
- **那么** 该点位的值在 tick 过程中必须保持不变

### 需求:变位总开关
界面必须提供一个总开关控制变位整体启停。关闭时所有点位必须停止变位;开启时所有 `enabled=true` 的点位必须恢复按各自配置变位。

#### 场景:总开关关闭停止全部变位
- **当** 多个点位正在变位,用户关闭总开关
- **那么** 所有点位必须立即停止变位,寄存器值不再被自动改变

### 需求:点位变位状态可查询与指示
后端必须提供查询"当前启用变位的点位及其模式"的能力。前端必须在寄存器表对应行展示该点位的变位启用状态与模式标识。

#### 场景:表格行显示变位模式标识
- **当** 某点位已启用 `increment` 变位
- **那么** 寄存器表中该行必须显示启用指示与递增模式标识
